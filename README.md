# Лабораторна робота - Цифри числа

# Опис
Програма, яка шукає суму та добуток цифр цілого десяткового числа та повертає кількість цифр у ньому.

# Структура файлів
- functions.h  - оголошення функцій і змінних
- functions.cpp - реалізація функцій
- main.cpp - головна функція
